# Data Analytics

## Visão geral

O Data Analytics é uma plataforma experimental de Big Data desenvolvida para demonstrar a ingestão, armazenamento, processamento e análise de grandes volumes de dados estruturados e não estruturados.

O projeto simula o ambiente de uma empresa que recebe dados provenientes de diferentes fontes, como avaliações e comentários de clientes, imagens, informações de atendimento e logs de sistemas.

## Fontes de dados

- Comentários e avaliações de clientes
- Imagens enviadas pelos usuários
- Dados estruturados de atendimentos
- Logs de sistemas e aplicações

## Objetivos

A plataforma será desenvolvida para:

- Processar dados em batch e streaming;
- Armazenar diferentes tipos de dados;
- Processar textos e imagens;
- Aplicar técnicas de Machine Learning;
- Identificar padrões e tendências;
- Monitorar o desempenho da infraestrutura;
- Aplicar princípios de governança, privacidade e segurança.

## Tecnologias

As tecnologias serão definidas e implementadas ao longo do desenvolvimento do projeto.
